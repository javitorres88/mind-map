# Mind Map — Chronic Conditions × AI

An interactive mind map with two main themes: **Chronic Conditions** and **Artificial Intelligence**.

🔗 **Live site:** https://javitorres88.github.io/mind-map/

## Features
- Two main branches: Chronic Conditions (light brown) & AI (light orange)
- Click any node to expand/collapse its subtree
- Expand all / collapse all controls
- Notebook-paper background with ruled lines
- Single self-contained `index.html` — works offline

## Files
- `index.html` — interactive mind map (main)
- `mind_map.md` — portable Markdown version

## Run locally
Just open `index.html` in any browser, or serve it:
```bash
npx serve .
```
